# ai3080 — 3× RTX 3080 20GB 本地推理机：硬件 + 基准 + 踩坑

一台自建的家用推理机的完整记录：硬件清单、引擎选型与调参、实测基准、以及一路上踩过的坑。
文档里的数据来自本机实测；无来源的推算我会明确标注。

> 全部内容已脱敏（内网 IP、Tailscale IP、用户名、GPU UUID、主机密钥均已替换为占位符）。

## 硬件

| 项目 | 规格 |
|---|---|
| CPU | AMD EPYC 7402（24C/48T，**AVX2，无 AVX-512**） |
| 内存 | 123 GiB DDR4（实测可用约 119 GiB） |
| GPU | **3× 魔改 RTX 3080 20GB**（GA102，`sm_86`，各 20480 MiB） |
| GPU 位置 | PCI `01:00.0` / `41:00.0` / `81:00.0`（各自独立 Root Complex，Gen4 x16） |
| GPU 特殊点 | A26R 魔改卡；**BAR1 仅 256 MB、ReBAR 未生效**；VBIOS 为 2020 首发版 |
| 驱动 | NVIDIA **610.57.04** + P2P 补丁（12/12 卡对 P2P OK） |
| 内核 | `7.0.0-31-generic`（**已 apt-mark hold**） |
| 磁盘 | Lexar NM620 256 GB NVMe（238.5 GB，**DRAM-less**） |

> 第 4 张 3080 于 2026-10-07 物理拆除，故当前 `gpu=[0,1,2]` 即全部卡。

## 主结果（Strata + Qwen3.8-Flash-Next UD-Q4_K_XL，262,144 上下文，3 卡）

| 指标 | 实测 |
|---|---|
| Prefill（~31k 唯一提示，中位） | **1,941 tok/s** |
| Decode（全新 256 token，中位，墙钟） | **64.4 tok/s** |
| Decode（引擎自报） | 79.9 – 93.2 tok/s（可预测内容可达 ~120） |
| 专家缓存命中率 | 96 – 99 % |
| 推理期磁盘读取 | **0**（`file_blobs`/`file_mb` 恒为 0） |
| 对话缓存 | 19,620–25,972 token 在 0.06–0.7 s 内恢复（约 100×） |
| 就绪时间 | 热页缓存 60–85 s；冷启 265 s；开视觉后 125 s |

**并发表（`parallel: 4`，每路唯一 nonce 提示）**

| 卡数 | N=1 | N=2 | N=4 |
|---|---:|---:|---:|
| 3 卡 | 59.1 t/s | 67.3（×1.14） | 80.8（×1.37） |
| 4 卡 | 70.4 t/s | 75.0（×1.07） | 97.9（×1.39） |

→ 第 4 卡相对 3 卡：N=1 **+19.1%**、N=2 **+11.4%**、N=4 **+21.2%**。
**结论：单人使用应关闭 `parallel`；第 4 张卡只在多路并发下才划算。**

## 三条硬红线（血泪）

1. **绝不设 `GGML_CUDA_P2P=1`** —— 出乱码且持久污染驱动状态（MTP 接受率归零，只有重启能恢复）；
2. **内核必须钉 `7.0.0-31-generic`** —— 7.0.0-34 及以上与该驱动组合会**静默损坏多卡数据**；
3. **正确性校验三件套**：`Paris` / `51` / `Jupiter`（每次改动后必须通过）。
